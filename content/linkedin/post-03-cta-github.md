O varejo brasileiro movimenta R$ 2,7 trilhões por ano.

E a maioria das decisões de gôndola ainda é tomada com planilha, gut feeling e reunião de alinhamento.

Não é falta de dado — é falta de uma forma rápida de cruzar dado estruturado com percepção do consumidor.

Foi isso que tentei resolver com o **Retail Analyst Crew**.

---

📦 **O que está no repositório**

✅ Geração de dados sintéticos com ShadowTraffic (20 marcas, 4 canais, sazonalidade mensal)
✅ Pipeline de ingestão de reviews no Qdrant via embeddings
✅ 3 agentes CrewAI orquestrados: SalesAnalyst + MarketResearcher + Reporter
✅ Interface conversacional com Chainlit (steps visíveis, streaming)
✅ Docker Compose para rodar tudo localmente em minutos

**Você faz uma pergunta em linguagem natural. O sistema:**
1. Consulta o banco de dados com SQL gerado automaticamente
2. Busca reviews semanticamente relevantes
3. Entrega um relatório executivo completo

---

🍫 **Por que chocolates?**

Porque é uma categoria com dados ricos, marcas conhecidas e sazonalidade clara — perfeita para validar se o sistema realmente responde perguntas de negócio com dados reais.

Lacta, Kit Kat, Ferrero Rocher, Sonho de Valsa — os dados são sintéticos, mas as perguntas são as mesmas que qualquer gestor de categoria faz toda semana.
